Recipe Checklist

Paste a recipe link. Get the ingredients and a step list you can tick off.

Some big sites (Allrecipes, Serious Eats, Simply Recipes and others) block link loading. The Send button reads the recipe from the page you already have open, so it works on those too.

On a computer

Drag this button onto your bookmarks bar (press Ctrl+Shift+B if the bar is hidden):

Send to Recipe Checklist

Then, on any recipe page, click it.

On iPhone or iPad

  1. In Shortcuts, tap + and name it Send Recipe.
  2. Add Run JavaScript on Web Page. Replace its script with this one:
  3. Add URL Encode (encoding the JavaScript Result).
  4. Add URL: type https://brotherpolo.github.io/recipes/#r= and then insert URL Encoded Text.
  5. Add Open URLs.
  6. In the shortcut's details, turn on Show in Share Sheet (receiving Safari web pages). In iPhone Settings › Apps › Shortcuts › Advanced, turn on Allow Running Scripts.
  7. On a recipe in Safari, tap Share › Send Recipe.

On Android (Chrome)

  1. Copy the button code:
  2. Bookmark any page (⋮ › ☆), then edit that bookmark: name it Send Recipe and paste the code as its URL.
  3. On a recipe page, tap the address bar, type Send Recipe, and tap the bookmark in the list.

On the recipe page, press and hold on the text, choose Select all, then Copy, and paste it here.
